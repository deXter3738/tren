# Icons

Tren's own colourful layered icons on a 24px grid, drawn for Tren (no third-party licence). Bright filled shapes, a lighter overlapping layer at about 90% opacity, small white details.

| Icon | Use |
|---|---|
| home | Home tab |
| calendar | Routines tab, "This week" |
| clock | History tab, "Last time" |
| cloud-check | Synced status |
| dumbbell | Exercises, exercise placeholder, "Last workout" |
| stopwatch | Time, rest timer |
| moon | Rest |
| layers | Sets |
| plate | Volume |
| trophy | New bests |
| bell | Reminders, "Next" |
| flame | Effort (RPE) |
| wifi-off | Offline |

Sizes: 20px in labels and chips, 24px in the tab bar. Unselected tabs render these in greyscale (`filter: grayscale(1)`, 70% opacity). Colours are fixed in the files and work on both themes.
